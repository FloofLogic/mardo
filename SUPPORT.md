# Mardo support

Use a public GitHub issue for a reproducible Mardo defect or a focused feature
request that can be discussed in public. Search existing issues first and use
the structured form so the report includes the release, macOS version,
hardware architecture, and smallest useful reproduction.

Do not publish:

- private or customer documents;
- license files, order details, receipts, or account information;
- credentials, tokens, crash dumps with private paths, or unreviewed logs; or
- details of an unpatched security vulnerability.

For purchase, license, redelivery, account, or private-file help, email
[support@mardo.app](mailto:support@mardo.app). You can also use Mardo's
**Help → Send Feedback** command for a private product report.

Security reports follow [SECURITY.md](SECURITY.md), never a public issue.
