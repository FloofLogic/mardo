# Mardo security policy

Please do not disclose an unpatched vulnerability in a public issue.

Use GitHub's
[private vulnerability report](https://github.com/FloofLogic/mardo/security/advisories/new)
to send the affected Mardo version, macOS version, impact, reproduction steps,
and any minimal non-sensitive evidence. If that route is unavailable, email
[support@mardo.app](mailto:support@mardo.app) with **Security** in the subject.

Floof Logic will acknowledge the report privately, investigate it, and
coordinate disclosure after affected users have a reasonable path to a fix.
The current public Mardo release receives security fixes; older builds may be
asked to update before further diagnosis.
